## 📝 What You Need to Do

### 1. Install Dependencies (5 minutes)
```bash
cd C:\Users\bgsmi\OneDrive\Documents\official-Deviji-event-page
npm install
```

### 2. Convert & Place Images (10 minutes)

Convert these 3 images to WebP and place in `public/assets/`:

| Filename | Source Image | Description |
|----------|-------------|-------------|
| `hero-banner.webp` | Hindi poster with dates | Event banner 27 Nov-10 Dec |
| `seated-stage.webp` | Speaker on white stage | Raseshwari Devi Ji seated |
| `close-up.webp` | Portrait with microphone | Close-up with garlands |

**Quick conversion:** https://cloudconvert.com/jpg-to-webp

### 3. Run & Test (2 minutes)
```bash
npm run dev
```
Opens at `http://localhost:5173`

### 4. Build for Production
```bash
npm run build
```
Creates `dist/` folder ready to deploy
