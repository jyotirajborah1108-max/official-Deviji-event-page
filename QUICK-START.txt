✅ DEPENDENCIES INSTALLED
   The node_modules folder is present, so npm install completed.

📋 WHAT YOU NEED TO DO NOW:

1️⃣  CONVERT IMAGES (10 minutes)
   ----------------------------------
   You need 3 WebP images in public\assets\:
   
   ├─ hero-banner.webp     (the Hindi poster with dates)
   ├─ seated-stage.webp    (speaker on white stage)
   └─ close-up.webp        (portrait with microphone)

   Convert at: https://cloudconvert.com/jpg-to-webp
   Set quality to 85%


2️⃣  RUN THE SITE (1 minute)
   ----------------------------------
   Open PowerShell in this folder and run:
   
   npm run dev
   
   Opens automatically at: http://localhost:5173


3️⃣  BUILD FOR PRODUCTION
   ----------------------------------
   When ready to deploy:
   
   npm run build
   
   Upload the 'dist' folder to your web host.


📁 PROJECT STRUCTURE
   ----------------------------------
   ✅ index.html          - HTML template

   ✅ public/

⚠️  IMPORTANT NOTES
   ----------------------------------
   • Image filenames must match exactly:
     - hero-banner.webp
     - seated-stage.webp  
     - close-up.webp
   
   • Place all 3 images in: public\assets\
   
   • After placing images, refresh browser if site is running
